# ERP 

# إنشاء نظام ERP مصغر لإدارة العملاء والمشاريع والتحليل المالي

أنت مهندس برمجيات وخبير UI/UX ومتخصص في بناء تطبيقات الأعمال الاحترافية.

قم بتصميم وإنشاء تطبيق ويب وسطح مكتب (Desktop Style Web App) باللغة العربية بالكامل (RTL)، احترافي وعصري، يعمل كمنصة متكاملة لإدارة العملاء والتحليل المالي ومتابعة المشاريع والفوترة.

## اسم النظام

منصة إدارة العملاء والتحليل المالي والمشاريع "شركة الاسطول الالي"

مرفق صورة الشعار الخاص بالشركة

---

# المتطلبات العامة

* واجهة عربية كاملة RTL

* تصميم احترافي حديث (Modern Enterprise Dashboard) متناسق مع الهوية البصرية للشعار المرفق

* Responsive لجميع الشاشات

* دعم الوضع الليلي والنهاري

* نظام صلاحيات للمستخدمين

* تسجيل العمليات (Audit Log)

* إشعارات ذكية وتنبيهات تلقائية

* بحث متقدم في جميع الشاشات

* تصدير PDF

* تصدير Excel

* طباعة التقارير

* رفع المرفقات والوثائق

* لوحة تحكم تفاعلية تحتوي على رسوم بيانية احترافية
