# Settings workspace

Gate 47 introduces a persistent settings workspace for the authenticated ERP.

The parent settings route keeps section navigation visible while child routes render their existing business forms. A new overview page explains each administrative area and gives one-click access to regional preferences, users, approvals, permissions, and readiness.

The layout uses logical RTL properties, a responsive two-column navigation grid on medium screens, and a sticky side navigation on desktop.

No database migration is required.
