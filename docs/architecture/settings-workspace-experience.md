# Settings workspace

Gate 47 introduces a consistent settings workspace for the authenticated ERP.

A shared shell wraps the existing regional, user, approval, permission, and permission-readiness routes. It keeps section navigation visible without changing the established TanStack route hierarchy or the business forms inside each page.

The layout uses logical RTL properties, a responsive two-column navigation grid on medium screens, and a sticky side navigation on desktop.

No database migration is required.
